# tools

Small, single-file, no ads, no tracking, no upload.

A collection of self-contained web utilities, each one a single HTML file with its markup, CSS, and JavaScript inlined. Nothing is fetched at runtime, and nothing you type or paste leaves the tab. Save the page to disk with Cmd-S and it still works offline.

## Tools

| Tool | What it does |
|---|---|
| [qr](tools/qr/) | QR code generator, encodes client side, PNG and SVG download |

More are coming.

## Rules

- One directory per tool with `index.html` and `meta.json`.
- Fully self-contained single file — all markup, CSS, and JS inlined.
- Zero runtime network requests — no CDN, no fonts, no analytics, no third-party anything.
- 50 KB gzipped budget per tool, printed in each tool's own footer.
- No framework and no bundler, only `shared/base.css` and `shared/shell.js`; the root `index.html` is generated by `scripts/build-index.mjs` from the `meta.json` files.
- Vanilla JavaScript only.
- Keyboard accessible with real labels, respects `prefers-color-scheme` and `prefers-reduced-motion`.

## Local development

```sh
node scripts/build-index.mjs      # regenerate root index
node scripts/check-size.mjs       # enforce the size budget
python3 -m http.server 8000       # serve, then open http://localhost:8000
```

No install step and no dependencies — Node is used only for those two scripts.

## Adding a tool

1. Copy `tools/qr/` to `tools/<slug>/` — it is the reference implementation.
2. Edit `index.html` with your tool's markup, CSS, and JS.
3. Write `meta.json` with `title`, `blurb`, `tags`, and `keywords`.
4. Run the two scripts.

## Deployment

Deployed to Cloudflare Pages with build command `node scripts/build-index.mjs`, output directory is the repo root, and custom domain `tools.jof.dev`. GitHub Actions runs the index build and size check on every push and pull request.

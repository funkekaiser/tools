A checksum is a fingerprint worked out from every byte of the file. Change a single byte and it comes out completely different, so a match means you have the same file the publisher fingerprinted. SHA-256 and SHA-512 cannot be faked. MD5 and SHA-1 are old: they still catch a damaged download, but whoever made a file can make a second one with the same MD5 or SHA-1. A match only proves something if the checksum came from the publisher's own site. SHA-3, BLAKE and CRC checksums are not checked here.
